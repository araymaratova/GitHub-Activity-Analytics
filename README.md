# GitHub-Activity-Analytics

Итоговый мини-проект по дисциплине «Programming for Data Analysis and Database»
(Big Data Analysis, магистратура, группа ADA-2603M). Кластер 1: Big Data Processing & SQL Analytics.

Анализ событий GitHub: типы событий, самые активные репозитории и пользователи,
языковые тренды. Источник данных: [GH Archive](https://www.gharchive.org) (почасовые JSON-дампы).

## Данные

- 30 подряд идущих часов: 2026-10-25 00:00 – 2026-10-26 05:59 (UTC)
- 2 188 124 события, 712 053 репозитория, 464 095 пользователей
- Размер CSV около 242 МБ, Parquet около 96 МБ, БД SQLite около 323 МБ
- Язык программирования в событиях GH Archive почти отсутствует (40 строк), поэтому язык
  дополнительно получен через GitHub REST API для топ-3000 самых активных репозиториев
  (покрытие: около 16,8% событий). Это расширение, согласованное с преподавателем.

Сырые данные и БД в репозиторий не входят (папка `data/` в `.gitignore`).

## Установка

Python 3.11.

```
py -m pip install -r requirements.txt
```

## Запуск

1. Скачать данные (30 часов, начиная с 25.10.2026): в `downloader.py` указана дата старта,
   затем `py downloader.py`
2. Запустить меню: `py main.py`
3. В меню по порядку: `1` (парсинг), `2` (замеры памяти и форматов), `3` (создание БД),
   затем пункты `4-9` (аналитика, сравнение подходов, графики, SQL-запросы).
4. Языки (необязательно): создать файл `token.txt` с токеном GitHub (без прав) и выполнить
   `py enrich_languages.py`. Без этого шага таблица языков будет почти пустой.

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | консольное меню |
| `config.py` | пути и настройки |
| `downloader.py` | скачивание файлов GH Archive |
| `json_parser.py` | построчный разбор JSON, запись CSV и Parquet чанками |
| `optimizer.py` | оптимизация памяти, сравнение CSV и Parquet |
| `enrich_languages.py` | получение языков репозиториев через GitHub API |
| `db.py`, `sql/schema.sql` | схема БД (3NF) и загрузка в SQLite |
| `queries.py` | 12 SQL-запросов (JOIN, GROUP BY/HAVING, CTE, подзапрос, оконные функции) |
| `analysis.py` | сравнение подходов и SQL vs Pandas |
| `visualize.py` | графики (`reports/plots/`) |
| `docs/er_diagram.png` | ER-диаграмма |

## Результаты

В папке `reports/`: таблицы замеров памяти, сравнение CSV и Parquet, сравнение подходов,
результаты SQL-запросов, графики.
